# Instruções para agentes

- Os PRDs devem ser **sempre** criados na raiz do projeto atual, seguindo o formato `docs/plans/{{YYYY-MM-DD}}-{{descrição}}.md`.
- Preserve os requisitos já aprovados no PRD antes de sugerir mudanças.
- Diferencie claramente funcionalidades implementadas, limitações do MVP e melhorias futuras.
- Não trate cor como único meio de comunicar feedback; mantenha navegação por teclado e rótulos acessíveis.
